# مساحة عمل المبيعات — Fontain Digital Solutions

هذا المجلد هو الذاكرة الدائمة لشغل المبيعات. كل جلسة جديدة مع المساعد تبدأ من صفر،
لذلك كل ما يستحق الحفظ يُكتب هنا ويُرفع للفرع.

## الملفات

| الملف | المحتوى |
|---|---|
| `fontain-brief.md` | تعريف الشركة والخدمات والباقات وقواعد البحث والرسائل. يُقرأ أولًا في كل جلسة. |
| `leads.md` | سجل العملاء المحتملين مع حالة كل واحد. يُحدَّث بعد كل تواصل. |
| `excluded.md` | شركات فُحصت واستُبعدت، حتى لا تتكرر في أي دفعة قادمة. |
| `pipeline.md` | فرص واعدة ناقصها رقم تواصل أو تحقق، للدفعات القادمة. |

## بداية أي جلسة

قل للمساعد:

> اقرأ `sales/` كاملًا ثم كمّل معي

## قاعدة مهمة

كل رقم في `leads.md` مصدره مقتطف نتيجة بحث، وليس صفحة مفتوحة مباشرة.
تحقق من الرقم على رابط المصدر قبل أول رسالة.
